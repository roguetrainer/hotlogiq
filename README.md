# HotLogiQ

Source for the [HotLogiQ website](https://hotlogiq.ca) — notes and working
papers on where cheap simulation of molecules stops being reliable, and how to
tell in advance.

The site is deliberately small. It carries results that survived an audit of the
underlying corpus; the ones that did not are gone rather than archived.
